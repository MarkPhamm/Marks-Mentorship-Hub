# Glossary

- **Mentee**: a student or early-career person Mark mentors 1:1 toward a data role.
- **Track**: the role a mentee aims at — data analyst, analytics engineer, or data engineer.
- **Playbook**: the public guides at github.com/MarkPhamm/Mentorships that mentees work through.
- **Spotter**: the Slack bot that posts each mentee's GitHub commit activity to the group daily.
- **Note**: the message sent with a LinkedIn connection request; it is the application to the mentorship.
- **Minion profile**: a candidate profile indistinguishable from a thousand others; what the mentorship exists to fix.
- **Copy-paste test**: could 1,000 other candidates paste this line unchanged? If yes, rewrite it.
- **Only-me test**: what is true about you that isn't true about the other candidates?
